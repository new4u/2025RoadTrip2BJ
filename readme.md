# 深圳到北京自驾游路线规划系统

## 项目概述
这是一个为2025年春节期间从深圳到北京的自驾游提供路线规划的系统。系统考虑了路线优化、休息点安排、充电站分布等多个因素。项目采用"虚拟职场"理念，通过直播方式提升任务执行效率和体验质量。

### 虚拟职场理念
- 将个人项目当作职场任务来执行
- 通过直播营造稳定的工作氛围
- 借助观众互动提高执行动力
- 以职场化方式提升任务完成度

### 核心目标
- 优化深圳至北京自驾路线（1月24/25日出发，28日凌晨到达）
- 重点规划大广高速服务区体验
- 合理利用春节高速免费政策（28日0时后）
- 通过直播记录全程规划执行过程

## 使用说明
1. 打开特斯拉浏览器访问直播页面
2. 允许摄像头和麦克风权限
3. 点击"开始直播"按钮开始推流
4. 可以通过"切换摄像头"按钮切换前后摄像头
5. 观众可以通过弹幕进行互动
